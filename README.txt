RELATÓRIO ESTÁTICO DE INCIDÊNCIA — NOELBIA

Abra o arquivo index.html diretamente no navegador.

Arquivos:
- index.html: interface completa do relatório.
- incidencia.json: cópia legível dos dados exportados.
- incidencia-data.js: os mesmos dados em formato carregável pelo HTML local.

Os dados são uma fotografia do banco no momento da exportação. Para atualizá-los,
execute novamente o script workers/document_processor/scripts/export_incidence_html_data.py.

Este diretório contém questões reais. Não publique seus arquivos em um endereço público.
